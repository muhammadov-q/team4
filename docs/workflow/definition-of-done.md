# Definition of Done

A story is done when:

- Its acceptance tests pass ([[workflow/issues]]).
- Tests are written with the code and pass locally and in CI ([[architecture/testing]]).
- Types and lint are clean.
- Docs are updated where relevant: the app's README, [[architecture/api-contract]] or an ADR.
- A teammate reviewed the PR and it's merged into `develop`.

The PR template (`.github/pull_request_template.md`) repeats this as a checklist.
